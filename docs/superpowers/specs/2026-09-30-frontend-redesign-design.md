# Easel 前端改版设计：画室 · 矿物色

- 日期：2026-09-30
- 范围：`web/frontend/`（React 19 + Vite + TypeScript）
- 状态：设计已确认，待评审本规格

## 1. 背景与目标

现在的界面有三个问题：
- 套的是通用 SaaS 卡片模板：白色圆角卡片、柔和阴影、蓝色和桃色的模糊色块、每张卡片一个图标方块，看不出是 Easel。
- 字体混乱：Manrope、Bodoni、Noto Serif SC 混用；Inter 加载了却没用上；中文落到系统字体。
- 各页组件风格不统一：黑色大按钮、带彩色左边框的卡片、中英混排的标题。

目标是让 Easel 有自己的视觉身份，在日常使用中清爽、耐看，同时把样式整理成可维护的体系。

用户已确认的决策：

| 决策项 | 结论 |
|---|---|
| 整体气质 | 画室 · 矿物色：白底配墨色，五层流水线各配一种国画矿物色 |
| 深色模式 | 只做浅色。颜色全部走变量，以后加深色只需补一套变量值 |
| 改动范围 | C 全面重构：换视觉 + 按流水线重组导航 + 抽出共用组件库 |
| 主按钮颜色 | A 墨色。矿物色只用来标流水线层，不用于按钮 |
| 样稿 | 工作台、对话、技能库、账号四页的样稿已确认（见 `.superpowers/brainstorm/` 下的 `visual-style.html`、`key-pages.html`） |

非目标：
- 后端 API、`lib/api.ts` 的请求与数据结构、`lib/store.ts` 的本地存储键、对话流式逻辑一律不改。
- 功能不增不减，唯一的新增是「创作数据」独立成页（内容来自工作台现有的卡片）。
- 不做深色模式，不做移动端专门的交互，只保证窄屏下不溢出、能用。
- 不改 `web/static/` 下的落地页。

## 2. 视觉系统

### 2.1 颜色

所有颜色只在 `styles/tokens.css` 里定义。组件和 TSX 里不允许出现十六进制颜色。

中性色：

| 变量 | 值 | 用途 |
|---|---|---|
| `--c-canvas` | `#F6F7F5` | 应用底色（画布） |
| `--c-surface` | `#FFFFFF` | 面板、输入框、弹窗（纸面） |
| `--c-side` | `#EEF0EC` | 主侧栏底色 |
| `--c-sunken` | `#F2F3F0` | 页内次级栏（对话记录栏）、空状态底 |
| `--c-tint` | `#EEF0EC` | 用户消息气泡、悬停底 |
| `--c-rule` | `#E3E6E1` | 分隔线、面板边框 |
| `--c-rule-strong` | `#D2D6D0` | 输入框边框、次要按钮边框 |
| `--c-ink` | `#1F2328` | 正文、主按钮底色 |
| `--c-ink-2` | `#4B5159` | 次要文字 |
| `--c-ink-3` | `#868C94` | 辅助文字、占位符 |

层色（矿物色）。每种色有三个变量：本色（色块、色条）、文字色（小字号上保证对比度 ≥ 4.5:1）、浅底（约 12% 透明度）：

| 层 | 颜料 | 本色 | 文字色 | 页面 |
|---|---|---|---|---|
| 发现 discover | 群青 | `#2F4E9C` | `#2F4E9C` | 热点雷达、爆款拆解 |
| 策划 plan | 赭石 | `#9A6034` | `#8A5530` | 选题库、内容日历 |
| 生产 produce | 朱砂 | `#C8412E` | `#B23A29` | 内容库（及对话产出） |
| 发布 publish | 石绿 | `#3E8E6E` | `#2F7358` | 发布中心、账号 |
| 归因 attribute | 藤黄 | `#D9A21B` | `#8A650C` | 创作数据 |
| 通用 general | 墨灰 | `#868C94` | `#4B5159` | 技能库、画像 |

变量命名为 `--layer-<key>`、`--layer-<key>-text`、`--layer-<key>-soft`。

语义色直接复用层色，不另起色系：

| 语义 | 值 | 用途 |
|---|---|---|
| `--c-ok` | 石绿 `#3E8E6E` | 已登录、成功、已配置 |
| `--c-warn` | 藤黄文字色 `#8A650C`，浅底 `--layer-attribute-soft` | 需配置 key、风控提示 |
| `--c-danger` | `#B4312A`（比朱砂更深，避免和「生产」层混淆） | 删除、失败、错误 |
| `--c-focus` | `#1F2328` | 焦点环 |

移除：
- 蓝青渐变（`--accent-gradient*`）
- 页面背景上的蓝色、桃色模糊色块
- 所有装饰性渐变

唯一允许渐变的地方是头像占位。

### 2.2 字体

| 角色 | 字体栈 | 用在哪 |
|---|---|---|
| 品牌字 `--font-brand` | `'Bodoni Moda', 'Didot', serif`，斜体 600 | 只用于侧栏的 Easel 字标 |
| 标题 `--font-serif` | `'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', serif`，600 | 页面标题、区块标题、面板标题、大数字、技能名、平台名 |
| 正文 `--font-sans` | `-apple-system, 'PingFang SC', 'Hiragino Sans GB', 'Noto Sans SC', 'Microsoft YaHei', sans-serif` | 其余所有文字 |
| 代码 `--font-mono` | `'SF Mono', Menlo, Consolas, monospace` | 只用于代码块和 key 脱敏串 |

字号阶（px）：

| 字号 | 用途 |
|---|---|
| 12 | 辅助 |
| 13 | 次要 |
| 14 | 正文 |
| 16 | 区块标题 |
| 20 | 弹窗标题 |
| 26 | 页面标题 |
| 34 | 大数字 |

其他排版规则：
- 正文行高 1.65，标题行高 1.25。
- 数字用 `font-variant-numeric: tabular-nums`。
- 正文段落最大宽度 72ch，对话气泡最大宽度 680px。

排版禁忌：
- 不用全大写标签。
- 不在标题里单独给某个词换颜色或加粗。
- 按钮和链接文字后面不加「→」。

### 2.3 形状、间距、阴影、动效

- **间距**：4px 基准，常用值为 4 / 8 / 12 / 16 / 20 / 24 / 32。
- **圆角**：分三级。
  - `--r-control` 6px：按钮、输入框、标签、导航项
  - `--r-panel` 10px：面板、列表容器
  - `--r-overlay` 14px：弹窗、抽屉
- **阴影**：只有浮层（弹窗、抽屉、下拉菜单）和对话输入框有阴影，面板靠 1px 边框分隔。
- **动效**：
  - 只保留回应操作的动效：弹窗和抽屉的出入场、展开收起、按钮按下。
  - 页面切换不加入场动画。
  - 尊重 `prefers-reduced-motion`：此时关闭所有过渡。
- **焦点**：所有可交互元素在 `:focus-visible` 时显示 2px 墨色外框，外偏移 2px。

### 2.4 标志性元素：流水线色条

这是全站唯一值得「大胆」的地方，其余元素保持克制：

- **工作台**：顶部是一条横跨全宽的五段色条，下面五栏各显示一个关键数字。五层本来就是有先后的流程，所以用顺序排列是合理的。
- **侧栏**：分组名前放一个 9px 的色块。
- **页头**：页面标题上方用色块加层名，标出这一页属于哪一层。
- **技能库**：每层的分段标题下面有一条 2px 的层色线。
- **对话**：技能运行标签前放一个层色小方块。

## 3. 字体加载

- 在 `package.json` 里新增依赖 `@fontsource/noto-serif-sc` 和 `@fontsource/bodoni-moda`。
- 在 `main.tsx` 里只引入需要的字重（文件名已对照 5.3.0 版的包核实）：
  - `@fontsource/noto-serif-sc/600.css`
  - `@fontsource/bodoni-moda/latin-600-italic.css`
- Noto Serif SC 的 `600.css` 包含各语种子集，每个子集都用 unicode-range 声明，浏览器只下载页面上真正用到的字。
- 从 `index.html` 删掉全部 Google Fonts 的 `<link>`（Bodoni、Manrope、Noto Serif SC、Inter）。
- 正文用系统字体，不下载网络字体。
- `dist/` 已被 gitignore。字体分片会让 `dist/` 变大，但不进仓库；首屏只加载实际用到的分片。

## 4. 信息架构与导航

### 4.1 主侧栏（`Sidebar.tsx`，宽 232px）

从上到下：
1. Easel 字标（图标 + Bodoni 斜体）
2. 画像选择
3. 导航
4. 底部状态栏

导航由新增的 `lib/layers.ts` 驱动：

```
工作台
对话
[群青] 发现：热点雷达、爆款拆解
[赭石] 策划：选题库、内容日历
[朱砂] 生产：内容库
[石绿] 发布：发布中心、账号
[藤黄] 归因：创作数据
技能库
画像
────
● 网关状态            设置
```

- **选中态**：白底 + 墨色文字（字重 600）+ 左侧 3px 墨色竖条。
- **底部状态栏**：去掉构建号 `subnav-1` 的显示。构建号仍保留在 `main.tsx` 的控制台输出里，值改为 `studio-1`。
- **窄屏**：视口宽度 < 1024px 时收成 64px 的图标条。此时隐藏文字和分组名，用 `title` 提示；画像选择收成头像按钮。

### 4.2 页面与路由

- `Page` 类型新增 `'analytics'`（创作数据）。
- 删除 `SubNav.tsx`：它承担的「子工具导航」已经由侧栏的分组取代。
- `lib/layers.ts` 是层信息的唯一来源，内容包括：
  - 层的 key、中文名、颜料名、CSS 变量名、说明文案
  - 每一层包含哪些页面（`Page` 到 layer 的映射）
  - `SkillPage` 的 `LAYER_META`、侧栏分组、页头层标记、工作台色条都从这里取。
- 层名统一为：发现、策划、**生产**、发布、归因、通用。`SkillPage` 里现在的「制作」改为「生产」。

### 4.3 对话记录移进对话页

- 会话列表（新建、切换、重命名、归档、删除、查看已归档）从 `Sidebar.tsx` 挪到对话页左侧的次级栏，拆成新组件 `ChatSessionList.tsx`，宽 236px，底色 `--c-sunken`。
- `App.tsx` 里的会话状态与回调不变，只是改为传给 `ChatPage`（或它的外层容器），不再传给 `Sidebar`。
- 视口宽度 < 1200px 时，会话栏默认收起，由对话页头的按钮展开。

## 5. 共用组件库（`src/components/ui/`）

每个组件一个 `.tsx` 文件，样式放在 `styles/ui/<组件名>.css`，由 `styles/index.css` 统一 import。

| 组件 | 要点 |
|---|---|
| `Button` | `variant: 'primary' \| 'secondary' \| 'ghost' \| 'danger'`，`size: 'sm' \| 'md'`，支持 `icon`、`loading`、`disabled`。高度：md 34px、sm 28px。primary 为墨底白字，secondary 为白底加边框，ghost 无边框，danger 为 `--c-danger` 文字（确认弹窗里是实心） |
| `PageHeader` | `layer?`、`title`、`description?`、`actions?`。标题 26px 宋体；有 `layer` 时标题上方显示色块和层名 |
| `Panel` | `title?`、`action?`（右上角的文字链接，比如「热点雷达」）、`children`。白底、1px 边框、10px 圆角、内边距 16/18px |
| `EmptyState` | `text`、`action?`。底色 `--c-sunken`，文案要写清楚下一步做什么 |
| `StatusDot` | `tone: 'ok' \| 'idle' \| 'warn' \| 'danger'`，加文字 |
| `Tag` | `tone: 'neutral' \| 'warn' \| 'ok' \| 'danger' \| layer`，小号浅底标签 |
| `LayerMark` | `layer`，色块加层名，页头和侧栏分组共用 |
| `Field` | `Input`、`Select`、`Textarea` 三种，统一边框、焦点态、禁用态 |
| `Modal` | 标题、主体、底部按钮区；Esc 关闭；打开时焦点移入，关闭后焦点回到触发元素。设置面板、扫码登录弹窗、引导向导、确认框共用 |
| `Tabs` | 横向标签页，用于设置面板的六个模型通道、内容库筛选等 |

现有的 `.btn`、`.card`、`.badge`、`.panel`、`.page-title` 等类由这些组件取代；迁移完成后删除旧类。

## 7. 样式架构

```
src/styles/
  tokens.css      颜色、字体、字号、间距、圆角、阴影、动效变量
  base.css        reset、body、滚动条、焦点环、reduced-motion、markdown 基础排版
  layout.css      应用外壳：侧栏、主区、窄屏规则
  ui/*.css        每个共用组件一个文件
  pages/*.css     每个页面一个文件（dashboard.css、chat.css、skills.css…）
  index.css       只负责按上面的顺序 @import
```

- 现有 1314 行的 `styles/index.css` 按上面的结构拆开；迁移完成后删除没人用的旧类。
- 迁移期间，`tokens.css` 为旧变量名（`--text`、`--border`、`--red`、`--layer-*` 等）保留别名，指向新变量，保证页面随时可用。全部迁移完后删除别名。
- TSX 里的内联样式：
  - 只允许与布局相关、需要动态计算的值（宽度、高度、`grid` 位置等）。
  - 颜色、字体、边框、阴影一律改用类名或变量。
  - 目前约 170 处内联样式需要逐个处理。

## 8. 不变的边界

以下内容不能改动行为：
- `lib/api.ts`、`lib/store.ts`、`lib/whoami.ts`、`lib/linkifyOutputs.ts`、`lib/sanitize.ts` 的逻辑

- `localStorage` 的键名
- 前端通过相对路径访问 API 的约定（`index.html` 里补结尾斜杠的脚本保留）

## 9. 验证

1. **构建与检查**：`npm run build`、`npm run lint`（不新增 warning）、`python -m pytest`（后端测试不受影响，但要确认）。
2. **截图对比**：用 Playwright 对 12 个页面加设置面板、扫码弹窗、技能抽屉、引导向导，分别在 1440×900 和 1024×768 两个尺寸下截改版前后的图，逐张检查，确认没有溢出、重叠或遗漏的旧样式。
3. **流程点测**（在真实运行的 `easel web` 上）：
   - 切换各页
   - 新建对话，重命名、归档、删除会话，查看已归档
   - 切换画像
   - 打开和关闭设置，切换模型通道标签
   - 打开扫码登录弹窗并关闭
   - 技能抽屉
   - 日历增删排期
   - 内容库预览
4. **无障碍**：
   - 所有可交互元素能用键盘到达，且焦点可见。
   - 正文与背景的对比度 ≥ 4.5:1。
   - 开启 reduced-motion 时没有过渡。
5. **评审**：独立的代码评审加一轮设计评审，对照本规格和样稿截图。

## 10. 风险与注意

- **与小红书登录修复冲突**：未提交的小红书登录修复也改了 `AccountsPage.tsx`。先让用户实测、提交那个修复，再开始改版，避免两件事混在一个提交里。
- **改动面大**：分期实施，每期结束时都要能构建、能用。页面之间文件独立，同一期内可以并行。
- **字体包体积**：`npm ci` 会多下载几十 MB 的字体包，只影响安装耗时，不影响运行。
- **会话栏移位的使用习惯**：会话栏移到对话页之后，在其他页面就看不到会话列表了。侧栏的「对话」项旁边显示当前会话标题，缓解这个问题。
